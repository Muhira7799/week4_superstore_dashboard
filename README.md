# Superstore Sales Dashboard - Week 4

## Overview
This project was completed as part of the AnalystLab Africa Data Analytics Internship (Week 4).

The goal was to analyze Superstore sales data and create an interactive Power BI dashboard that provides meaningful business insights.

## Dataset
- Superstore Sales Dataset

## Tool Used
- Microsoft Power BI

## Dashboard Features
- Interactive Dashboard
- KPI Cards
- Sales Trend Analysis
- Sales by Region
- Sales by Category
- Underperforming Products
- Map Visualization
- Slicers (Year, Region, Category)

## KPIs
- Total Revenue: 2.30M
- Total Profit: 286.40K
- Total Orders: 5K
- Profit Margin: 12%
- Sales Growth: 42%
- Top Region: West
- Best Selling Category: Technology

## Key Insights
- West generated the highest sales and profit.
- Technology is the best-selling category.
- Tables, Bookcases, Supplies, and Fasteners are the lowest-performing sub-categories.
- Sales trends help identify business performance over time.

## Recommendations
- Invest more in the West region.
- Continue promoting Technology products.
- Improve low-profit sub-categories.
- Use sales trends to support future business planning.
